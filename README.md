> Visit 👉 [https://jobs-and-interns.github.io](https://jobs-and-interns.github.io)

---

## 🎯 Mission

Our mission is simple — **empower Sri Lankan undergraduates** by connecting them directly with **verified, paid, and meaningful opportunities** while enabling companies to **find exceptional early talent** with ease.

We’re proud to maintain a **trusted, community-driven platform** with:
- 🎓 Over **12,000+** active student members  
- 🏢 **50+ partner companies** across industries  
- 🌍 **59,000+ social media followers** nationwide  
- 💼 100% **verified** paid job & internship listings

## 🧩 Features

## 🚀 Getting Started

Follow these steps to run and edit the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/jobs-and-interns/jobs-and-interns.github.io.git

# 2. Open the folder
cd jobs-and-interns.github.io

# 3. Open index.html in your browser
````

> 💡 You can use any code editor (VS Code recommended) to make modifications.
> To deploy changes, push updates to the **main** branch — GitHub Pages will automatically rebuild.
